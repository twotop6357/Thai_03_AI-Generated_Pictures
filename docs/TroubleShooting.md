# TroubleShooting

치명적 장애 기록이다. 절차는 [AGENTS.md](../AGENTS.md)를 따르고, 기록한 항목은 [HANDOFF](agents/HANDOFF.md)에서 연결한다.

## 작성 기준

- 다음과 같은 장애는 **해결을 기다리지 않고** 즉시 기록한다: 크래시, 프리즈, 첫 화면 복귀 불가, 데이터 손실, 보안 정보 노출, 의도치 않은 위험 동작(PC 종료, 작업 스케줄러 변경, 실제 API 전송), 장시간 운영 중 메모리 증가, 배포를 막는 빌드 실패.
- 발견자가 문제와 재현 조건부터 기록하고 HANDOFF에서 연결한다.
- 문제, 원인, 해결법은 각각 1~3문장으로 쓴다. 원인이 확정되지 않았으면 `조사 중` 또는 `추정`으로 표시하고 확인 방법을 적는다.
- 재현하거나 검증하지 않은 해결을 `해결`로 표시하지 않는다.
- 단순 경고나 일반 TODO는 장애가 아니다. [TODO](../TODO.md)에 적는다.
- 실제 키, 토큰, 개인정보를 첨부하지 않는다.

```markdown
- 발견: 일시(YYYY-MM-DD HH:mm +09:00), 발견자, 환경(에디터/빌드, 장비), 재현 조건
- 상태·담당:
- 문제:
- 원인: (확정 / 추정 / 조사 중)
- 해결법:
- 검증: 수행자, 환경, 시나리오, 결과, 증거 위치
- 재발 방지:
```
